# Yike Niu — Academic Homepage

Static academic homepage for GitHub Pages. No build tools or dependencies are required.

## Preview locally

Run `python3 -m http.server 8000` in this directory, then open http://localhost:8000.

## GitHub Pages configuration

Target account: oliver-nyk
Target repository: oliver-nyk.github.io
Expected address after successful publication: https://oliver-nyk.github.io/

Publish from the main branch, root directory (/), in Settings → Pages.
The .nojekyll file makes GitHub serve the static files directly.

## Maintain

- index.html: biography, publications, and links
- style.css: responsive layout and portrait framing
- script.js: BibTeX copying and WeChat dialog
- Yike_Niu_CV.pdf: downloadable CV
- adatempo-insertion-conveyor.gif: insertion simulation, then real-world conveyor
- pam-overview.png: PAM figure
- profile-photo.jpg: portrait source, with CSS framing
- wechat-qr.jpg: WeChat QR code

The header includes CV, GitHub, X (@OliverNiuY), and WeChat.
No Sites configuration, credentials, or source history are included.
